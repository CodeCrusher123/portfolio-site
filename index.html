About Me

I'm a frontend developer learning TypeScript by actually building stuff. I started with the usual HTML, CSS, and JavaScript, then got into making things interactive — rendering content with JS, breaking code into modules, and figuring out why the DOM wasn't doing what I told it to. Recently I built a weather app in TypeScript using Tailwind CSS for the first time. That one got me working with API data, real-time forecasts, handling user search, and updating the UI based on events. Most of what I've learned came from breaking things and debugging them until they worked.
